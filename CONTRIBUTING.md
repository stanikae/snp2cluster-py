# Contributing to SNP2Cluster-Py

Contributions are welcome via GitHub issues and pull requests.

## Development Workflow
1. Create a feature branch from the default development branch.
2. Add or update tests for any behavioral changes.
3. Run the complete test suite (`python -m pytest -q`).
4. Run `git diff --check` to ensure clean code.
5. Document any user-facing changes in the README and CHANGELOG.
